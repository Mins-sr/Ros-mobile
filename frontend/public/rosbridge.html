🤖 ROS2 Web Control

GitHub Pages + rosbridge でリアルタイムROS2制御

📡 セットアップ手順

1. ROS2環境でrosbridgeサーバーを起動してください:

ros2 launch rosbridge_server rosbridge_websocket_launch.xml

2. 下記の接続URLを設定して「接続」ボタンをクリック

3. パブリッシャー/サブスクライバーを制御できます

WebSocket接続 切断
